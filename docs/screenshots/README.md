# Screenshots

Drop PNGs here with these exact names and the README picks them up:

| File | What to capture |
|---|---|
| `init-providers.png` | `opencc init` — the provider list with a couple of providers |
| `init-provider-detail.png` | a provider opened, showing its fields |
| `init-testing.png` | `t` pressed — the spinner, then the OK/FAILED lines |
| `server-banner.png` | `opencc` — the startup banner with the whole chain |
| `claude-running.png` | `opencc claude` — Claude Code working on something |

Until a file exists its image shows as broken on GitHub, so either add them
before pushing or drop the `![...]` lines from the README.
